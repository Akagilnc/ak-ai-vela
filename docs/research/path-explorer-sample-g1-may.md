# Path Explorer Sample · G1-G3 5 月（"动物自然"兴趣线样板）

**定位**：这是"动物自然"这一条兴趣线的 G1-G3 五月内容样板。两个目标——(1) 把内容做成**标签池形态**（一张卡身上挂一组属性标签，靠标签筛+组合，不是一段各写一套）；(2) 内容密度做到**家长照着明天就能落地**。不是最终内容，但已超出形态 prototype。

**卡片标签模型（锁定 5 个）**：

每张卡 = 一个中性内容单元，挂以下一组（多值、不互斥）标签。没有哪张卡天生是"招牌卡"，"懂你娃"是拿娃的画像去这组标签里筛+组合的结果。

1. **年级跨度**（12 / 6 / 3）—— 这内容在几个年级里还成立。纯复用/内容保质期属性，靠难度档调节，**与"有多个性化"无关**（这是两根独立的轴）。
2. **兴趣方向** —— 可多值。本样板线 = 动物 / 自然科学 / 生态观察。
3. **触发类型**（三态）—— `月度 baseline`（routine 底盘）/ `event`（特定 trigger 触发的一次性包）/ `baseline 支撑`（结构像 event、功能是日常高频底盘，如家门口生态）。
4. **时间窗** —— 节气 / 假期 / 季节段。event 卡被它定义。
5. **户外 / 室内** —— **挂子活动，不挂整卡**。很多卡是室内+户外混合包（如 baseline、立夏），挂整卡会让偏室内的家庭筛掉整卡时连带丢掉本可保留的子活动。

**城市不进标签**：城市是"分区"轴不是"筛选"轴——跨城是另一套内容（场馆/路线/物种全不同），不是同池 hide 几张。当下只有上海，**文件层面交代一次（全样板默认上海），每张卡不盖城市戳**；跨城以后按目录/库结构分。

**结构**：1 张月度 baseline + 4 张 event（5 月碰巧 4 个 event 叠加：劳动节假期 / 立夏 / 东滩迁徙尾声 / 初夏家门口生态，适合 stress-test 富 event 月份）。

**内容单元 = 原子卡 + 策展视图（讨论收敛结论，锁定）**：

- **卡按原子写**：一卡 = 一个自足活动，每个标签单值。捆绑卡（如旧"月度 baseline""立夏"）拆成原子（立夏·外观察 / 立夏·斗蛋 / 立夏·秤人 / …）。authoring 阶段原子化不花额外成本，但永不用回头拆包。
- **"本月计划 / 节气段"是策展视图，不是手写大卡**：视图层 = **写好的策展散文（引子 / 心法 / 串场 / 产出 / serendipity）+ 一个被匹配原子填充的槽**。永远不是 raw 查询结果——偷懒不写策展散文，就退化成标签 dump 清单（硬规矩）。
- **触发类型是两根轴，不是一个三态枚举**：①排期（常驻当月 / 时间窗触发：节气|假期|季节窗）②节奏角色（一次性重包 / 高频轻底盘 / **年度复发仪式**）。立夏 = 窗口触发 + 年度复发仪式；硬塞普通 event 会丢掉"每年回看见一年变化"的累积属性。
- **填充槽 = 策展混合槽，不是匹配筛选**：严格按兴趣筛是自毁——靠看娃广试、看什么粘住才逐渐懂。槽 = 贴身（贴当前理解）+ 探索（**故意 off-profile**，按试错成本排序：顺路/门槛低/时长短优先）。
- **兴趣标签 = 排序权重，不是闸门**；显式"不喜欢"负反馈是唯一硬门。**硬门逻辑现在就建进模型**——只是「用户怎么提交负反馈」这个输入机制推迟（见下方推迟边界）。没有负反馈输入 → 硬门永不触发 → 系统自然跑"默认包容、探索席位足"，**这是 day-1 设计上的正确形态，不是占位 stub**。
- **配比是"家庭运营风格"轴的函数，不是全局常数**（基础设计就要这样设计）：
  - **两根独立的轴，别混**：①娃兴趣/特质轴（v0.6 学术框架管）→ 决定贴身**喂什么内容**；②家庭运营风格轴（爱尝鲜 vs 嫌麻烦 / 时间预算 / 折腾容忍度）→ 决定**探索给多少 + 探索能多折腾**。
  - **家庭风格吐两个耦合输出**：探索配比 + **折腾天花板**。嫌麻烦型 = 探索照给（广试才长出懂）但只走 0 门槛原子（家门口/阳台），不塞远途；爱尝鲜+时间足型 = 配比高且远途大包可进探索池。物流标签（顺路/门槛/时长）就是"折腾"这把尺。
  - `50 : 50` 仅为**无任何信号时的人群兜底**，不是人人目标值。
  - 配比 / 折腾天花板必须是**集中可配置的值（非散落硬编码）**——这个值**现在就建**（一个 config 常量即可，不需要花哨调参 UI）。
- **推迟边界（精确，别再扩大化）**：唯一推迟的是**「用户怎么提交负反馈」的输入机制**（家长告诉 Vela"娃不喜欢这个"的 UX + 存储 + 回灌抑制）。**展示层、策展视图、贴身/探索混合、家庭风格函数、折腾天花板——全部现在建，跑在无信号默认上。** 家庭风格信号起手也走人群兜底 50/50；co-maker（Kailing）按既定原则**间接反推不直接问**，不在此 build 的阻塞项里。
- **探索项文案 = 邀请式正向**（"很有趣，娃可能喜欢，有时间不妨一试"），不要论证式（"又不亏/正好顺路"）。顺路/低门槛是后台排序理由，**绝不写成给家长看的理由**。详见 memory `feedback_curation_copy_voice`。

**Event 卡策展铁律**（从 5 月策划过程确立）：
> **Rule 1 · Route-specificity**：每张 event 卡必须 serve 其 route 的核心 thesis（对"小小动物科学家" = 动物 / 自然科学 / 生态观察）。**不是 calendar grab-bag**——日历上的事件（比如母亲节）即使和时间窗 overlap，如果和 route thesis 无 substantive 联系，**不进本 route**。
>
> **Rule 2 · 跨 route 潜力不否定 event 价值**：被本 route 拒绝的 event（如母亲节）可能是**其他 route 的好卡**（"亲子情感 / 家庭教育 / 艺术文学" 等未来 route 的 candidate）。Park 到 `docs/research/path-explorer-other-route-candidates.md`（暂未创建）以备 v0.2+ 加 route 时调用。
>
> **Rule 3 · 兴趣是卡的标签，不是硬绑的归属**：兴趣方向是卡身上的一个标签（可多值）。本样板线所有卡的兴趣标签 = 动物自然。跨兴趣线靠"兴趣"标签筛+组合，不靠把卡硬绑死在一条 route 上——同一张低门槛卡（如家门口生态）以后可能同时挂多条兴趣线。
>
> 后续月份（6/7/8/9/10/11/12）策展对齐此规则。

**Navigation model（架构决定）**：
`/path/little-animal-scientist` 是 **month-by-month navigation**（月份视图分开，不是单页 scroll）。打开时默认进入**当前月**（by 访问时间，2026 年 5 月 18 日打开就进 5 月视图）。家长可以：
- 当前月：看 baseline + 该月所有 event
- 点其他月份（月份导航 bar / dropdown / grid）切过去查看
- 月份之间互不 visual 干扰，当前月 focus 清晰

具体月份导航 UI（tab / grid / sidebar）Day 2 组件 prototype 时再定。

## 🗓️ 5 月底盘 · G1-G3 — 原子+策展视图

> **"月度 baseline" 本身不是一张卡，是策展视图（= 本月计划）。** 它的槽由"常驻底盘"原子按家庭风格混合填充。下半原子清单是 authoring 单元，家长看不到这是分开的。

### 一、策展视图（家长看到的"5 月底盘"）

**一句话**：5 月春末夏初，天气刚好。周末 routine 2-3 次小 action 保持观察本在用。

**时间占用**：一个月 3-5 次 weekend 半天。≤ 总周末时间 40%，留一半以上给别的。

**做什么**（周末选做，不追求全做）：
> 槽 = 常驻底盘原子按"贴身 + 探索"混合（配比 = 家庭风格函数，无信号兜底 50/50）。"娃偏自然观察 + 家庭嫌折腾"读数下的一种填法示例——

- **贴身**：`小区/公园观察 walk`、`观察本记录` —— 0 门槛、家门口，跟她在做的连得上
- **探索（低折腾天花板）**：`场馆·自博动线` —— 室内一次性、就在市区，文案给家长：「自博的恐龙厅很震撼，娃多半会看住，挑个不挤的周末去一次」
- 嫌折腾的家庭，`场馆·海洋馆` / 远的不进这家的槽；爱尝鲜+时间足的，探索席位才放更重的

**产出**：本子多 1-3 页图文；场馆去 1 次（累积）；杂志看 1-2 篇；视频 1-2 期。

**心法**：5 月是过渡月，不追求"做什么大事"。你能坚持 4 月的 routine 就是胜利。

### 二、原子卡清单（authoring 单元，每个标签单值；触发全部 = 常驻底盘）

| 原子 | 年级跨度 | 兴趣 | 节奏角色 | 户外/室内 | 内容 |
|---|---|---|---|---|---|
| 小区/公园观察 walk | G1-G12 | 自然 | 高频轻底盘 | 户外 | 春末夏初素材密度最高（落花/新叶/第一批小虫）。带本子 walk 10-20 分钟，想画什么画什么，频次不强求 |
| 观察本记录 | G1-G12 | 跨兴趣底盘 | 高频轻底盘 | 任意 | 干啥都接 1 页。她自己的方式随便画写。（与立夏共用同一原子） |
| 《博物》5 月号阅读 | G1-G12 | 自然+文化 | 高频轻底盘 | 室内 | 到家翻一翻，挑 1 篇一起读 |

| 场馆·上海自然博物馆动线 | G1-G3（带分档） | 自然 | 一次性重包（月 1 次） | 室内 | 见下方完整动线（原文保留） |

**原子内容（场馆两条动线原文保留，挂在对应原子上）**

`场馆·上海自然博物馆动线` —— 5 月推荐自博或海洋馆（室内，天气稍热更舒适）。避开 5/1-3 人流峰值，挪 5/4 或 5/5。

**上海自然博物馆 · G1-G3 推荐路线（90 分钟，按龄调档）**：

1. 进门先直奔 **生命长河**（恐龙 + 古生物大厅）— 20-25 min。视觉冲击强，全龄高能区。
2. 转 **生态万象** 看上海 / 华东本土生态 — 15-20 min。她在东滩 / 动物园看到的活物，这里能看到 permanent 展陈版本。
3. **探索中心** 互动玩 — 20-25 min。小孩能摸能玩的展区，注意力尾声释放。
4. 礼品店 5 min（她选 1 个 ≤ ¥50 的小东西，建立"博物馆正向记忆"）。

**按龄调档**（同一条线，难度旋钮拧一下，不是另写一条）：
- **G1**：上面 4 步原样。每区停留短，重"看到 + 有印象"，不要求记名字。家长全程带。
- **G2**：每区多停 5-10 min；生态万象让她**自己找** 1-2 种"在东滩见过的"，建立"展陈 ↔ 野外"对应。回家本子记 2-3 种。
- **G3**：路线她**自己看导览图带路**；生命长河加一个"挑一种最感兴趣的回家查它吃什么/活在哪个年代"的小任务；探索中心选一个互动展深玩而不是走马观花。家长退到旁观。

_[具体展区位置以自博当日导览图为准，展区会不定期更新 — 家长可提前 [snhm.org.cn](https://www.snhm.org.cn) 查当月特展]_

`场馆·上海海洋水族馆动线` ——

**上海海洋水族馆 · G1 推荐路线（90 分钟）**：

1. **海底隧道** 先给她 wow 体验 — 10-15 min。水下穿行感 = 很多 G1 第一次。
2. **长江区（中国淡水）** — 15-20 min。中华鲟 / 扬子鳄这些本土物种，可以讲"这些动物就住在离我们不远的长江"。
   - 💬 **可以讲的小故事**（家长现场点开看，挑一个讲）：
     - 中华鲟是"活化石"——1.5 亿年前就在地球上，比恐龙活得还久
     - 中华鲟每年会从东海游回长江产卵，一路能游 2000 多公里
     - 扬子鳄是地球上只有中国才有的鳄鱼，全世界就它一种"只住中国"
     - 长江江豚被叫"微笑天使"，但全球只剩约 1000 头
3. **非洲区 + 南极区** — 20-25 min。看大型鱼 + 企鹅。
   - 💬 **可以讲的小故事**：
     - 企鹅不是"北极动物"——南极才有野生企鹅，北极没有
     - 企鹅的翅膀不是用来飞的，是演化成了"游泳桨"
4. **互动触摸池**（若开放）— 10-15 min。
5. 出口 5 min。

_[展区以馆当日实际开放为准，[sh-soa.com](https://sh-soa.com) 查当日动线]_

## 🎯 劳动节 5 天段（5/1-5/5）— 原子+策展视图

> **这张是"折腾天花板"轴最干净的样板**：路径 A/B/C 就是低/中/高折腾，槽按家庭风格 × 时间预算选。

### 一、策展视图（家长看到的）

**触发条件**：每年 5/1-5 假期。2026 年为 5/1（周五）到 5/5（周二）。
**前置**：家里有基本出行 planning 能力，没特别要求。
**时间预算**：5 天里用 **1-2 天** 做 nature-themed 活动，3-4 天给家庭别的事。不要 5 天全排 Vela。

**做什么**（选一条路径，不贪多）：
> 槽 = 出行原子按"家庭折腾天花板 × 时间预算"填（不是按龄硬分）。两种家庭风格读数下的填法示例——

- **嫌折腾 / 时间紧**：贴身 + 探索都落在 `世纪公园` / `佘山`（市区或市郊日返，0-低折腾）。文案：「佘山 5 月虫子多起来了，娃会玩得开，半天来回不累」
- **爱尝鲜 + 时间足**：探索席位可放 `宁波雅戈尔` / `南京红山`（2-3 天，高折腾）。文案：「红山动物园本土动物特别全，娃八成会迷上，假期里挑两天去」
- `崇明东滩观鸟` 兴趣窄（纯观鸟），偏自然观察的娃才进贴身；否则只在"那几天本来就要去崇明"时作低优先探索

**产出**：一次 mini-trip，照片若干 + 观察本上 1-2 页新地方的记录。

**避坑**：5/1-3 上海各场馆人流峰值。提前预约票 + 尽量挪到 5/4 或 5/5。

**心法**：劳动节不是"冲刺日程"，是"改变节奏"的机会。让她看到平常不看到的地方，不在于多。

|---|---|---|---|---|---|
| 世纪公园 / 共青森林公园 | G1-G12 | 自然 | **极低**（市区，不出远门） | 户外 | 家门口 walk + 观察本。几乎对任何家庭都可作探索项 |

> **样板自检**：①暖话（时间预算/产出/避坑/心法）逐字保留 ✅ ②路径 C 算账原文保留，转为池排除规则 ✅ ③折腾天花板轴在此卡显式落地，槽按家庭风格选非按龄硬分 ✅ ④探索文案邀请式，折腾度没写成用户可见理由 ✅

## 🌱 立夏节气段（5/5 或 5/6）— 原子+策展视图样板

## 🏠 初夏家门口生态段（5/20 之后）— 原子+策展视图

> **"baseline 支撑"三态的原型卡，也是全样本"0 折腾全员探索原子"的标杆**：试错成本≈0，所以它进**几乎每个家庭的探索席位**——不管娃兴趣、不管家庭嫌不嫌折腾（因为根本没折腾）。正文逐字保留（你满意）。

### 一、策展视图（家长看到的，正文未动）

**触发条件**：每年 5 月下旬起（上海大致 5/20 后），气温稳定 20°C 以上，第一批初夏物种开始在城市绿化 / 小区 / 公园大量出现。
**前置**：家附近有任何绿化（小区内花坛 / 楼下绿地 / 社区公园即可）。完全 0 门槛。
**时间**：一次 15-30 分钟。可以拆成一周 2-3 次，每次 15 分钟。

**为什么特别**：前面几张卡（场馆 / 东滩 / 节气）都有某种"去某处 / 某日做某事"的 barrier。这张卡反过来——**告诉家长她家 50 米内就有 100 种生物**。低门槛、高频次，是月度 baseline 的支撑面。

**5 种家门口可见的初夏生物**（带辨识特征）：

| 图 | 物种 | 家门口哪看 | 怎么让 G1 记住 |
|---|---|---|---|
| `[图：菜粉蝶停花上]` | 菜粉蝶（白蝴蝶） | 小区花坛，任何开花植物 | "白色小蝴蝶"—— 她第一个认识的蝴蝶 |
| `[图：玉带凤蝶飞行]` | 玉带凤蝶（大黑黄蝴蝶） | 公园里，飞得高 | "大蝴蝶"—— 比菜粉蝶大 3 倍，她一眼能感觉出"不一样" |
| `[图：蚂蚁搬食物]` | 家蚁 / 黑蚁 | 任何人行道砖缝 | 带她看 **蚁道**（一队蚂蚁搬东西的路线）—— 社会性昆虫第一印象 |

_(Vela ship 时图片内嵌在卡里)_

**怎么做**（随意组合）：

1. **蚁道观察**（15 分钟）：选一段有蚂蚁活动的人行道砖缝，和她一起蹲下来看 **5 分钟**。看蚂蚁从哪到哪、搬什么、怎么遇到同伴。回来本子画一条蚁道。
2. **蝴蝶追踪**（20 分钟）：小区花坛边等 5 分钟，通常会有 1-2 种蝴蝶来。不追蝶（小孩跑得慢），只看它停下来的那几秒。
3. **潮虫探险**（10 分钟）：搬开花盆 / 石头 / 落叶堆，看底下的西瓜虫 / 蚯蚓 / 各种小东西。**用手轻轻碰一下西瓜虫**，看它蜷成球。G1 对这种即时 feedback 最有感。
4. **楼下鸟声**（5 分钟）：阳台静坐，听不同的鸟叫。麻雀的"喳喳" / 斑鸠的"咕咕" / 白头鹎清晨的歌声。她能分出 2 种就够。

**产出**：本子上的 "家门口生物 count"——一个月累积能记 10-20 种。这个数字她自己看着会长骄傲。

**避坑**：

- **别用昆虫盒装回家**。G1 好奇心强 easily escalates 到 "抓"。教育重点是**观察在野外**，不是"带回家养死"。
- **别用杀虫剂 / 驱蚊液喷她的观察对象**。她看蝴蝶不用喷。
- **别强求"记住拉丁名"**。中文名 / 她起的外号 / "那种会飞的蓝蝴蝶" 都行。

**心法**：自然不只在远方的保护区。家门口 50 米内就有完整的城市生态系统。这张卡的真正价值 = **让她每天下楼的路变成实地课堂**，门槛为 0，频次无限。长期下来，她对"自然"的语言会从"我在公园里看到过"变成"我家楼下的麻雀今年比去年少"。

这是城市 G1 孩子的**唯一低成本、高频次、可持续的自然连接方式**。东滩 / 自博是 monthly events，家门口生态是 daily baseline。
