## V2 prompt（修正版，2026-05-15 同日）

修正版回答 = V1 + 以下 3 条澄清：

**1. 用户路线：中国籍美本国际生路线为主线（深度），美籍 return-to-US 路线作为差异点 surface（不深入）**

- 真实目标用户的大头是**中国籍走美本国际申请池**的家庭 —— 不管孩子在国内读国际学校 / 双语学校 / 公立体系，最终都以国际生身份申美本
- 美籍娃人在大陆（return-to-US）只是早期种子用户场景，**人群基数小**，不该当主线研究
- 主线要覆盖的关键节点（这些都按中国籍国际生路线深入研究）：
  - **K-12 学校体系选择**：公立 vs 双语 vs 纯国际学校（IB / A-Level / AP / 体系混合）—— 不同体系的申美本差异
  - **课程体系决策**：AP / IB / A-Level 三选一 / 双修，什么时间点决定，trade-off 是什么
  - **国际生申请池的真实竞争**：录取率 / SAT 中位数 / 文书取向 / 推荐信来源差异
  - **国际生身份 vs 美籍/绿卡身份在录取池里的差距**（这层 evidence 很关键）
  - **中国大陆申请季的特殊节奏**（标化考点紧张、签证、寄递、网络）
  - **中文母语 + 中国成长背景在文书 / 面试 / 选校策略里怎么用好**（不是回避，是用作 differentiator）
- 美籍 return-to-US 路径作为**差异点 surface**（占 15-20%）：在相关节点旁标 "如果孩子持美国护照，以下节点不同" —— 比如可以申美高获 domestic 待遇优势、SAT 国内考点限制不同、签证非问题、申请池切换可能性

**比例**：中国籍国际生路线主线 75-80%，美籍 return-to-US 差异点 15-20%

**2. 美高申请：作为 G7-G9 的重要分支节点写透，但不是全文主线**

- Andover / Exeter / Choate / Deerfield / Hotchkiss 这一档顶级寄宿中学申请是部分家庭的**可选分支**，不是必经路径
- 真实情况：中国家庭里，**少数**会在 G6-G7 申美高、**多数**会继续读国内国际学校到 G12 再申美本 —— 两条路 trade-off 不同
- 研究里给到的深度：
  - 申请时间窗（什么年龄申请、几年级转轨、申请季节点）✓ 写清楚
  - **走美高 vs 直升国际学校到 G12 的 trade-off**（学术准备、推荐信来源、申请池差异 — 包括美高生在美本申请池的 domestic 待遇优势 vs 国内国际学校生留在国际池、家庭分离成本、孩子成熟度匹配）✓ 重点写
  - 美高内部择校（顶级寄宿 vs 顶级走读 vs 中档）✗ 这层不要展开，太枝节
- **占报告权重**：G7-G9 这段的 30-40%，全报告的 5-8%

**3. 预算：定性 + 数量级，不要给具体报价**

- **不要列"每阶段需要花 X 万"这种数字** —— 这会让报告读起来像中介报价单，而且具体数字对家庭决策 anchor 不对
- 我要的是**结构性的钱信号**：
  - **inelastic（必须花的）vs elastic（可省的可选的）** —— 这是最有用的分类
  - 比如：标化考试报名费 = inelastic，名校文书一对一顾问 = elastic
  - 国际学校学费 = inelastic（如果选了这条路），但**选这条路本身是 elastic decision**
- **数量级标签**：每个开支项标 **低 / 中 / 高**（比如 "每年 1 万以下" / "每年几万" / "每年十几到几十万" 这种宽区间），不给具体数字
- 重点 surface："**业内常见但其实可省 / 被夸大的支出**" —— 比如低龄段一对一标化、5 年长约升学顾问、不必要的高端夏校。这类信息对家长价值最高

**额外补充给研究者的两点：**

- **不要假设家庭预算上限** —— 报告读者可能是预算 30 万/年的，也可能是预算 5 万/年的。每个开支项尽量说清楚"如果不花会有什么后果"，让读者自己判断
- **如果发现某些花钱项目其实更多是营销建构的需求**（不是真有 admission impact），明确指出来。这种 myth-busting 是这份报告最有价值的部分

## 三家工具的反应观察（2026-05-15）

- **Claude.ai Research**：启动前显式反问 3 个澄清问题 → 用户回答后再开始研究。Plan 一旦锁死就 commit
- **ChatGPT Deep Research**：直接开始研究，但启动后**可中断 + 接受 mid-run plan 修改**。可以发 V2 进去调整方向
- **Gemini Deep Research**：发不出去（启动后输入框锁死 / 单纯 bug）。最终用了 V1 的默认假设跑
