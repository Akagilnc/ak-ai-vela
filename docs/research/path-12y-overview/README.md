## 交叉验证用法

四份各自基于不同 base model + 不同 search coverage + 不同 prompt 处理方式产出。具体使用顺序：

1. **先单独读**每一份，记录主要 claim + structure
2. **对照表**：列每份在以下维度上的 claim：
   - 阶段切分（4 段 / 5 段 / 6 段 / 不分段？）
   - 美高申请权重（必经 / 可选分支 / 完全跳过？）
   - 标化窗口（G7-G8 / G9-G10 / G11-G12？）
   - 顾问介入时机（G1 起 / G6-G8 / G11-G12？）
   - 反共识（每家警告了什么坑）
3. **高置信结论**：多家共识 + 都引用了同源（NACAC / College Board / 顶校 college counseling office）的 claim
4. **存疑结论**：单家独说 / 没 source / 各家说法冲突的，标红、留待真顾问验真

## 重要提示：内容判断 vs 引用判断

ChatGPT 5.5 Pro 这份用了 inline `￼` citation marker 但没展开 source 列表（桌面版限制）。这意味着每条具体主张（"Andover REA 截止 2 月 1 日"、"NACAC 76.8%" 之类）**仍需二次核实**才能直接进产品文案。

Deep Research 模式的产出通常会展开 source URL + access date，那时再用更靠谱的 reference 替换。
