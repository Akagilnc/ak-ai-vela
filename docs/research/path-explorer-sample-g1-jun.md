# Path Explorer Sample · G1-G3 6 月（"动物自然"兴趣线样板）

**定位**：这是"动物自然"这一条兴趣线的 G1-G3 六月内容样板。两个目标——(1) 把内容做成**标签池形态**（一张卡身上挂一组属性标签，靠标签筛+组合，不是一段各写一套）；(2) 内容密度做到**家长照着明天就能落地**。不是最终内容，但已超出形态 prototype。

**卡片标签模型（锁定 5 个）**：

每张卡 = 一个中性内容单元，挂以下一组（多值、不互斥）标签。没有哪张卡天生是"招牌卡"，"懂你娃"是拿娃的画像去这组标签里筛+组合的结果。

1. **年级跨度**（12 / 6 / 3）—— 这内容在几个年级里还成立。纯复用/内容保质期属性，靠难度档调节，**与"有多个性化"无关**（这是两根独立的轴）。
2. **兴趣方向** —— 可多值。本样板线 = 动物 / 自然科学 / 生态观察。
3. **触发类型**（三态）—— `月度 baseline`（routine 底盘）/ `event`（特定 trigger 触发的一次性包）/ `baseline 支撑`（结构像 event、功能是日常高频底盘，如家门口生态）。
4. **时间窗** —— 节气 / 假期 / 季节段。event 卡被它定义。
5. **户外 / 室内** —— **挂子活动，不挂整卡**。很多卡是室内+户外混合包（如 baseline、立夏），挂整卡会让偏室内的家庭筛掉整卡时连带丢掉本可保留的子活动。

**城市不进标签**：城市是"分区"轴不是"筛选"轴——跨城是另一套内容（场馆/路线/物种全不同），不是同池 hide 几张。当下只有上海，**文件层面交代一次（全样板默认上海），每张卡不盖城市戳**；跨城以后按目录/库结构分。

**结构**：1 张月度 baseline + 3 张 event（6 月有 3 个 event 叠加：端午节假期 / 入梅家门口生态 / 夏至萤火虫，适合展示梅雨季和初夏独特的物候与季节稀缺感。芒种节气与世界海洋日已被评估并因G1-G3吸引力不足而有意排除）。

**内容单元 = 原子卡 + 策展视图（讨论收敛结论，锁定）**：

- **卡按原子写**：一卡 = 一个自足活动，每个标签单值。捆绑卡（如旧"月度 baseline"）拆成原子（端午·草药识别 / 端午·粽叶来源 / 观萤·时间窗 / …）。authoring 阶段原子化不花额外成本，但永不用回头拆包。
- **"本月计划 / 节气段"是策展视图，不是手写大卡**：视图层 = **写好的策展散文（引子 / 心法 / 串场 / 产出 / serendipity）+ 一个被匹配原子填充的槽**。永远不是 raw 查询结果——偷懒不写策展散文，就退化成标签 dump 清单（硬规矩）。
- **触发类型是两根轴，不是一个三态枚举**：①排期（常驻当月 / 时间窗触发：节气|假期|季节窗）②节奏角色（一次性重包 / 高频轻底盘 / **年度复发仪式**）。端午 = 窗口触发 + 年度复发仪式；硬塞普通 event 会丢掉"每年回看见一年变化"的累积属性。
- **填充槽 = 策展混合槽，不是匹配筛选**：严格按兴趣筛是自毁——靠看娃广试、看什么粘住才逐渐懂。槽 = 贴身（贴当前理解）+ 探索（**故意 off-profile**，按试错成本排序：顺路/门槛低/时长短优先）。
- **兴趣标签 = 排序权重，不是闸门**；显式"不喜欢"负反馈是唯一硬门。**硬门逻辑现在就建进模型**——只是「用户怎么提交负反馈」这个输入机制推迟（见下方推迟边界）。没有负反馈输入 → 硬门永不触发 → 系统自然跑"默认包容、探索席位足"，**这是 day-1 设计上的正确形态，不是占位 stub**。
- **配比是"家庭运营风格"轴的函数，不是全局常数**（基础设计就要这样设计）：
  - **两根独立的轴，别混**：①娃兴趣/特质轴（v0.6 学术框架管）→ 决定贴身**喂什么内容**；②家庭运营风格轴（爱尝鲜 vs 嫌麻烦 / 时间预算 / 折腾容忍度）→ 决定**探索给多少 + 探索能多折腾**。
  - **家庭风格吐两个耦合输出**：探索配比 + **折腾天花板**。嫌麻烦型 = 探索照给（广试才长出懂）但只走 0 门槛原子（家门口/阳台），不塞远途；爱尝鲜+时间足型 = 配比高且远途大包可进探索池。物流标签（顺路/门槛/时长）就是"折腾"这把尺。
  - `50 : 50` 仅为**无任何信号时的人群兜底**，不是人人目标值。
  - 配比 / 折腾天花板必须是**集中可配置的值（非散落硬编码）**——这个值**现在就建**（一个 config 常量即可，不需要花哨调参 UI）。
- **推迟边界（精确，别再扩大化）**：唯一推迟的是**「用户怎么提交负反馈」的输入机制**（家长告诉 Vela"娃不喜欢这个"的 UX + 存储 + 回灌抑制）。**展示层、策展视图、贴身/探索混合、家庭风格函数、折腾天花板——全部现在建，跑在无信号默认上。** 家庭风格信号起手也走人群兜底 50/50；co-maker（Kailing）按既定原则**间接反推不直接问**，不在此 build 的阻塞项里。
- **探索项文案 = 邀请式正向**（"很有趣，娃可能喜欢，有时间不妨一试"），不要论证式（"又不亏/正好顺路"）。顺路/低门槛是后台排序理由，**绝不写成给家长看的理由**。详见 memory `feedback_curation_copy_voice`。

**Event 卡策展铁律**（从 5 月物候确立）：
> **Rule 1 · Route-specificity**：每张 event 卡必须 serve 其 route 的核心 thesis（对"小小动物科学家" = 动物 / 自然科学 / 生态观察）。**不是 calendar grab-bag**——日历上的事件（比如母亲节、父亲节）即使和时间窗 overlap，如果和 route thesis 无 substantive 联系，**不进本 route**。
>
> **Rule 2 · 跨 route 潜力不否定 event 价值**：被本 route 拒绝的 event 可能是**其他 route 的好卡**（"亲子情感 / 家庭教育 / 艺术文学" 等未来 route 的 candidate）。Park 到 `docs/research/path-explorer-other-route-candidates.md`（暂未创建）以备 v0.2+ 加 route 时调用。
>
> **Rule 3 · 兴趣是卡的标签，不是硬绑的归属**：兴趣方向是卡身上的一个标签（可多值）。本样板线所有卡的兴趣标签 = 动物自然。跨兴趣线靠"兴趣"标签筛+组合，不靠把卡硬绑死在一条 route 上——同一张低门槛卡（如家门口生态）以后可能同时挂多条兴趣线。
>
> 后续月份（6/7/8/9/10/11/12）策展对齐此规则。

**Navigation model（架构决定）**：
`/path/little-animal-scientist` 是 **month-by-month navigation**（月份视图分开，不是单页 scroll）。打开时默认进入**当前月**（by 访问时间，2026 年 6 月 18 日打开就进 6 月视图）。家长可以：
- 当前月：看 baseline + 该月所有 event
- 点其他月份（月份导航 bar / dropdown / grid）切过去查看
- 月份之间互不 visual 干扰，当前月 focus 清晰

具体月份导航 UI（tab / grid / sidebar）Day 2 组件 prototype 时再定。

## 🗓️ 6 月底盘 · G1-G3 — 原子+策展视图

> **"月度 baseline" 本身不是一张卡，是策展视图（= 本月计划）。** 它的槽由"常驻底盘"原子按家庭风格混合填充。下半原子清单是 authoring 单元，家长看不到这是分开的。

### 一、策展视图（家长看到的"6 月底盘"）

**一句话**：六月是节气挤、雨水多的过渡月：端午 3 天小长假、入梅前后家门口生态突变、萤火虫高峰只开一周窗。每件事都不必大投入。

**时间占用**：4 个半天左右 · 端午一段 + 家门口若干 + 萤火虫一晚。≤ 总周末时间 35%，留一半以上给别的。

**做什么**（周末选做，不追求全做）：
> 槽 = 常驻底盘原子按"贴身 + 探索"混合（配比 = 家庭风格函数，无信号兜底 50/50）。"娃偏自然观察 + 家庭嫌折腾"读数下的一种填法示例——

- **贴身**：`观察本记录`、`《博物》6 月号阅读` —— 0 门槛、家门口，跟她在做的连得上
- **探索（低折腾天花板）**：`B 站陪看` —— 室内一次性，文案给家长：「无穷小亮的雨后昆虫科普极富幽默感，娃看了一定哈哈大笑，挑个下雨的周末晚上一起看看吧」
- 嫌折腾的家庭，重包或远途不进这家的槽；爱尝鲜+时间足的，探索席位才放更重的，例如 `6 月底 · 暑期预备`

**产出**：本子上 "6 月观察清单"——至少 1 个雨季动物 + 1 个夜观记录。两条就够。

**心法**：六月节气密、家长容易想"全都做"。挑 1 件做透比 4 件都做一半强。她记住的是"6 月看了一次萤火虫"，不是"做了 6 件事"。家门口反而是观察"自然有节奏"的最好实验室，因为变化是孩子能在 1 周内自己看见的。

## 🎯 端午 3 天段（6/19-6/21）— 原子+策展视图

> **这张是"折腾天花板"轴最干净的样板**：路径 A/B/C 就是低/中/高折腾，槽按家庭风格 × 时间预算选。

### 一、策展视图（家长看到的）

**触发条件**：每年 6/19–6/21 端午节假期。2026 年端午节假期为 6/19（周五）到 6/21（周日）。

**前置**：家里有基本出行 planning 能力，没特别要求。

**时间预算**：3 天小长假里用 **1 天** 做核心安排，30 分钟家里草药互动，其余时间留给家庭别的事。不要 3 天全排满。

**做什么**（选一条路径，不贪多）：
> 槽 = 出行原子按"家庭折腾天花板 × 时间预算"填（不是按龄硬分）。两种家庭风格读数下的填法示例——

- **嫌折腾 / 时间紧**：贴身 + 探索都落在 `闵行浦江郊野公园` 或 `嘉定毛桥集市`（市区或市郊日返，低折腾）。文案：「浦江郊野公园有端午文化节，民俗市集很热闹，地铁直达，半天来回极方便」
- **爱尝鲜 + 时间足**：探索席位可放 `江浙短途采杨梅`（3 天，高折腾）。文案：「端午刚好碰上浙江杨梅季中后期，民宿采摘体验极佳，娃多半会吃得开心，挑个两天去一次」
- 不想出门则选择 `家里搞艾草与粽叶`，让孩子摸、闻、认新鲜艾草与菖蒲，包 5 个粽子，体验同样深刻。

**产出**：本子上画 艾 + 菖蒲 + 箬叶 3 种叶子的轮廓——不必精确，记住"形状不同"就行。

**避坑**：端午期间长途奔波容易被堵在路上。江浙短途出行需避开高速 6/19 早 + 6/21 晚两次出行峰值。

**心法**：节日仪式 = 一年一次的物候记忆锚点。她明年 6 月再闻到艾草，会自动想起"哦端午"。这种气味记忆比"端午是纪念屈原"留得更久。

**原子内容（草药与粽叶细节原文保留，挂在对应原子上）**

`端午草药识别` —— 现场认 3 种，菜场或花市均可买到。

**端午草药 · 现场认 3 种**：

1. **艾草（Artemisia argyi）** —— 灰绿色绒毛叶，揉碎闻 → 苦清香。常见用法：挂门 / 泡脚水。
2. **菖蒲（Acorus calamus）** —— 长条剑叶，闻起来像姜 + 柠檬。和艾草成对挂门驱虫。
3. **雄黄** —— 不是植物，是**含砷矿物粉**，加热分解出三氧化二砷（剧毒、可经吸入累积）。别让孩子接触粉末，也不要让她去闻。古方点额头是仪式感不是药用，**看图认识就行**。

`粽叶其实是箬竹叶` ——

**粽叶其实是箬竹叶（鲜叶 vs 干叶）**：

- **科普**：粽叶不是"竹子的叶子"，是**箬竹（Indocalamus tessellatus）**专门长的宽叶子。江浙家庭包粽用鲜箬叶煮过（消毒 + 软化），北方多用芦苇叶。让孩子比较：**新鲜箬叶 vs 干箬叶**，气味差异很明显。
- **[避坑]**：**市售"粽叶"多数是干箬叶**——颜色偏褐绿、硬。如果想让孩子见到鲜叶，菜场端午前 1 周问"鲜粽叶"，或者江浙短途路上的农家最稳。

## 🌱 入梅家门口生态段（6/19前后 1周）— 原子+策展视图

> **"baseline 支撑"三态的原型卡，也是全样本"0 折腾全员探索原子"的标杆**：试错成本≈0，所以它进**几乎每个家庭的探索席位**——不管娃兴趣、不管家庭嫌不嫌折腾。正文逐字保留。

### 一、策展视图（家长看到的，正文未动）

**触发条件**：2026 上海入梅常年平均 6 月 19 日前后（中下旬，气象局每年临 7 日内公告） · 入梅当天 + 1 周内黄金窗口。

**前置**：家附近有任何绿化（小区内花坛 / 楼下绿地 / 社区公园即可）。完全 0 门槛。

**时间**：一次 15-30 分钟。可以拆成一周 2-3 次，每次 15 分钟。

**为什么特别**：入梅当天 + 之后 1 周是黄金窗口——第一场连续雨之后小生物集体出现。错过这 1 周，很多就回到土里了。这张卡反过来——告诉家长她家 50 米内就有 100 种生物。低门槛、高频次，是月度 baseline 的支撑面。

**5 种雨后家门口可见的动物**（带辨识特征）：

| 图 | 物种 | 家门口哪看 | 怎么让 G1 记住 |
|---|---|---|---|

不求 5 种全看到，能认出 1-2 种就是这一次的收获。

**怎么做**（雨后 30 分钟随意组合）：

1. **蜗牛与蛞蝓对比**（10 分钟）：雨后清晨 7 点前出门，在绿化带墙根找一找。让孩子指出哪只是蜗牛（有壳），哪只是蛞蝓（无壳鼻涕虫）。
2. **蚯蚓大救援**（10 分钟）：在人行道上寻找爬出来的蚯蚓，用小木棍轻轻把它们拨回到旁边的湿润泥土里，避免被太阳晒干。
3. **西瓜虫探险**（10 分钟）：搬开花盆或湿木头，轻碰西瓜虫看它蜷成球。科普它其实是**陆生甲壳类**（跟虾蟹是一家，不是昆虫）。
4. **傍晚听蛙鸣**（10 分钟）：傍晚 7–9 点在小区水景边闭眼静听 1 分钟，分辨青蛙的声音。

**产出**：本子上 "雨后清单"——一次能记到 2–4 种。3 次累积下来，她对家门口物种数量会有自己的估计。

**避坑**：
- **别在滑石板上跑**：雨后小区大理石台阶极滑，务必慢步走。
- **注意赤链蛇**：上海市区罕见但闵行 / 浦东郊野公园偶尔有**赤链蛇**（属游蛇科，**2024 中国蛇咬伤救治指南列为无毒蛇**；但牙锋利且**唾液菌群易引起细菌感染**，被咬需立即就医清创）。看到立即拉开距离，**不要尝试抓或赶**。
- **蚊虫防范**：蚊子开始密。穿长袖。**给孩子用儿童浓度驱蚊液**（DEET ≤ 30% 或派卡瑞丁 ≤ 20%）。<u>3 岁以下避免柠檬桉油（OLE / PMD）</u>。

**心法**：“雨后第二天 7 点”是一个观察习惯 (routine)。一旦养成，她以后听到下雨就会期待第二天能看到什么。这是观察习惯，不是知识点。

## ✨ 夏至萤火虫段（6/21-7/15）— 原子+策展视图

> **这段是单一深原子**（观萤，兴趣较窄，夜间高折腾）+ 一组 backup 原子。正文逐字保留。

### 一、策展视图（家长看到的，正文未动）

**触发条件**：夏至到 7 月中旬（2026 夏至 = 6/21） · 闷热无月光的夜晚最佳。

**前置**：夜间出行心理准备（不怕黑、能遵守安静不亮光的指令）。

**时间**：1 个夜晚 · 出发到回家约 4 小时（市区点）/ 6 小时（远郊）。

**为什么特别**：上海近郊萤火虫高峰在夏至到 7 月中旬（约 2026/06/21 – 07/15，部分点位窗口偏窄）。再早成虫期未到，再晚密度骤降。每年只开这一扇窗，错过等下一年。

**怎么做**（现场观萤指引）：

1. **出发前查公众号**：夜场是否对外开放、当年密度都会变。出发前必须查所选点位当年的官方公众号（上海植物园 / 辰山 / 滨江森林公园），有官方夜赏活动最稳。
2. **关闪光灯 / 关手机屏**：强光会让萤火虫熄灯并失去交配信号。
3. **适应黑暗**：到了先等 5 分钟让眼睛适应黑暗。一开始什么都看不到很正常。
4. **不抓不摸**：萤火虫寿命只有 1–2 周成虫期，抓一只就少一只。
5. **安静享受**：不需要刻意，只是别大声招呼小孩"快来看"。
6. **带防蚊液**：林下夏夜蚊子凶，提前做好防蚊。

**产出**：本子上 1 页 "6 月夏至看萤火虫"——看到 / 没看到 都写。如果没看到，写"明年再来"。这是 portfolio 里"自然没保证"的诚实记录。

**避坑**：萤火虫数量在不同年份波动很大。自驾往返数小时可能因为气温、农药或光污染一只也看不到，小孩挫败感重。预先和孩子做好“看不到也是自然规律”的沟通。

**备选方案 · 看不到怎么办**（找不到或者天公不作美）：
- **纪录片陪看**：BBC《地球脉动》"夜的世界"集有萤火虫长镜头。回家陪她看 5 分钟。
- **经典动画**：《虫师》动画第 8 话"重穴"——以萤火虫为主题，画面唯美深邃，能留下深刻的心灵记忆。
- **建立元认知**："等一年再来"的体验本身就是教育。

**心法**：萤火虫给孩子的不是知识，是"季节性的稀缺"。一年只能看一次的东西，比每天都能看的更让她记住。"等一年再来"的体验本身就是教育。
